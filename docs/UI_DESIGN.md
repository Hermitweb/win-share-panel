# WinShare Panel UI 设计规范

> 浅蓝调 · 轻渐变扁平化 · 新拟态柔光磨砂玻璃风
> 版本：v1.1  |  更新日期：2026-11-19
> 适用：WinShare Panel 控制面板全部界面与应用图标

---

## 一、设计理念

### 1.1 风格定位
**轻渐变扁平化 · 新拟态柔光磨砂玻璃风**

清新治愈、年轻化、轻量化。拒绝厚重写实、锐利硬边、暗深色系与写实厚涂。让一个原本偏"系统工具"的文件共享控制面板，呈现出现代 App 的柔和质感，降低使用者的心理负担。

### 1.2 情绪调性
- 安静、文艺、温柔、简约治愈
- 悬浮轻盈，不压迫
- 信息清晰但不冰冷

### 1.3 设计禁区
- 复古厚重质感
- 暗深色系为主调
- 尖锐棱角与硬直角
- 写实厚涂、金属反光、强高光
- 厚重硬阴影

### 1.4 反说明书原则（界面自解释）

**界面不是说明书。** 信息应靠图标、布局、交互本身传达，而不是靠成堆的小字注释补充。

AI 生成界面最常见的通病：给每个功能按钮配一行辅助小字，把页面塞满说明文字。结果是用户读字而不是用界面，密度失控、一级信息被注释淹没。本项目对此设立硬约束：

**禁止**
- 在按钮/字段旁写解释其行为的注释（如「点击后立即保存」「勾选后任务栏常驻图标」）
- 复述标签已经表达的含义（如字段名是「磁盘低水位阈值（GB）」，就不再补「共享所在盘剩余空间低于该值时标黄提醒」）
- 用括号、小尾巴、冒号从句堆叠补充条件（`-2=未映射` 保留在标签里，其余解释不要挂在正文）
- 长段说明块（>1 行）出现在常规页面；页脚只允许一句必要的边界提示

**允许 / 替代方案**
- 需要解释的细节 → 移进 `ToolTip`（悬停才显示，不占布局、不挤视觉层级）
- 字段名本身承载语义（标签写全，如「匿名 UID(-2=未映射)」）
- 状态反馈 → 用标签色、图标、MessageStrip/Toast 表达，而不是静态说明句
- 空状态 → 一句行动指引 + 一个主按钮（「还没有共享」+「新建共享」）
- 危险/不可逆动作 → 确认框文案（此时说明是必要的）

**自检（提交前逐条过）**
1. 页面上是否有句子在解释"你刚看到的那个控件"？→ 删。
2. 去掉某句小字，界面是否仍然自解释？→ 能，就删。
3. 新增说明前先问：能不能用标签、图标、状态色、悬停提示代替？→ 能，就不用正文。

**给 AI 的提示词约束（写进任何 UI 任务的 prompt）**
> 不要给按钮或字段添加解释性小字说明；界面靠图标、布局、交互自解释。确有必要解释的细节放进 ToolTip。字段标签写全（含取值含义），标签外不再重复说明。空状态给一句行动指引 + 一个主按钮，不要写成说明书段落。

### 1.5 文案层级规范
| 场景 | 写法 | 反例 |
| --- | --- | --- |
| 字段标签 | 自带取值含义的短词组 | 「端口」+ 小字「1-65535」 |
| 空状态 | 一句指引 + 一个按钮 | 「还没有共享，本页用于管理共享列表……」 |
| 状态/错误 | 短句，去掉括号补充 | 「尚未体检（点击重新体检枚举账号）」 |
| 页脚 | 至多一句边界提示 | 三行长段说明 |
| 补充解释 | ToolTip | 正文常驻小字 |

### 1.6 硬性规则（评审与 AI 生成时逐条核对，不满足即打回）

1. **搜索/输入框必须有可见占位符**：占位符由输入框模板（Adorner）绘制，不得被输入框背景遮盖；空输入框在截图中必须能看出"这是搜索框"。
2. **表头不得重名**：同一张表内出现两个相同表头（如两个「端口」/两个「认证」）即视为歧义缺陷——协议专属列必须带协议限定或按当前协议动态显隐。
3. **列不得裁字**：表头与单元格文字被裁切（"NFS权限"→"NFS权"、"SMB"→"SM"、"删除"→"删"）视为渲染缺陷；必须给足宽度或改为图标 + Tooltip。
4. **操作列必须可达**：行内最后一个动作被容器右边界裁掉、或在断点下消失，视为 P0；破坏性动作（删除）必须有独立可见入口或溢出菜单。
5. **弹窗不得使用系统默认控件样式**：弹窗内 CheckBox / RadioButton / TextBox / ComboBox 必须引用应用级 soft 样式（CheckBoxSoft 等），不得出现系统蓝方块。
6. **弹窗底部必须固定操作条**：内容区滚动、按钮固定；任何功能控件不得被按钮压住或被裁掉。
7. **同类弹窗不得重复叠加**：打开前检查是否已存在同类型窗口，改为聚焦已有窗口。
8. **常驻正文禁止账号清单/枚举长串**：账号、路径、枚举值只以候选项（下拉/选择器）形式出现，不做全量罗列。
9. **空态必须有行动指引**：一句状态 + 一个主按钮，不超过两个动作；无空态的页面视为缺陷。
10. **计数类元信息进标题行**："200 条 / 5min / 已跳过 2 项"等不得独占正文行。
11. **加载态必须有结构**：超过 2 秒的加载必须给骨架行或可数进度，不得留白。
12. **模式类菜单项必须显示当前值**：主题/模式用可勾选项（IsCheckable），不用"切换到…"把状态藏在动词里。
13. **断点常量单一来源**：侧栏折叠阈值与表格隐藏列阈值必须来自同一套断点常量，避免区间错位（1024–1099 这类宽度同时命中两套规则）。
14. **截图验收**：每个改动必须实机截图复核（含 1600 / 1024 两档宽度与深浅两套主题），不得以代码推断代替截图。
15. **键盘焦点必须可见**：所有可聚焦控件（按钮/复选框/输入框/下拉）必须有键盘焦点指示——按钮类挂主题化
    `FocusVisualStyle`（键盘 Tab 时显示主色虚线环，鼠标点击不出现），输入类用 `IsFocused` 边框高亮；
    禁止出现"Tab 走了一遍却看不出焦点在哪"的控件。弹窗/抽屉打开时焦点移入容器（`MoveFocus(First)`），
    Esc 必须可关闭（有未保存修改时走确认，不静默丢弃）。

## 二、色彩体系（浅蓝调 · v2.3 饱和科技蓝玻璃拟态）

> v2.3 视觉重制：参考"全平台总控"风格稿——饱和科技蓝主色 + 玻璃拟态卡面 + 蓝/紫/绿/橙四色 hue 徽章体系。
> 下表为 `Theming/ThemeTokens.Light.xaml`（深色字典同名镜像，深海军蓝玻璃变体）。

### 2.1 主色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 科技蓝 | `#2E6FDE` / `#6FA3F0` | 主操作、导航高亮、品牌色（白底 4.7:1） |
| 辅色 · 紫罗兰 | `#8B7CE8` / `#B0A6F2` | 次级强调、图表渐变 |
| 点缀 · 玫粉 | `#E85D75` / `#F597A8` | 提示、徽标、暖色点缀 |
| hue·蓝 | `#3584EC` | 统计徽章/协议磁贴（SMB） |
| hue·紫 | `#8B5CF6` | 统计徽章/协议磁贴（NFS） |
| hue·绿 | `#1FA97C` | 统计徽章/协议磁贴（FTP） |
| hue·橙 | `#F08C1A` | 统计徽章/协议磁贴（WebDAV） |
| 背景 · 纯净白 | `#FFFFFF` | 主背景、卡面 |
| 背景 · 浅蓝雾 | `#EDF4FC` | 分区底、输入衬底 |
| 文字 · 深海军蓝 | `#2F4159` | 主文字 |
| 文字 · 雾灰 | `#5E7488` | 次级文字（AA 4.5:1+） |

### 2.2 渐变方案（饱和蓝通透渐变）

主渐变（主按钮、品牌）：
```
linear-gradient(135deg, #3584EC 0%, #2456D6 100%)
```
导航选中胶囊：`#306EE8 → #2350C8`（对白字 ≥4.5:1）。

辅助渐变（卡片光晕、背景氛围）：
```
linear-gradient(135deg, #E3F0FD 0%, #EDEBFB 100%)
```
页面背板：`#E9F2FC → #F3F8FE → #EDEFFB`；Hero 横幅：`#DCEBFC → #EFE9FC`。

### 2.3 色彩质感
- 半透明叠透：图层相交处自然混色；窗口装饰光斑层透过玻璃半透衬底隐现
- 无强烈明暗阴影，色调统一和谐（卡片禁用 DropShadowEffect，层次由边框+渐变卡面承担）
- 透明度建议：磨砂层 72%–88%，装饰光斑 40%–50%（深色 16%–20%）

## 三、造型与圆角

### 3.1 圆角规范
| 元素 | 圆角 |
|------|------|
| 应用图标外框 | 大圆角方形（iOS/安卓裁切规范） |
| 卡片 | 16–20px |
| 按钮 | 10–14px |
| 输入框 | 10px |
| 标签/徽标 | 8px 或胶囊形 |
| 弹窗 | 16px |

### 3.2 造型语言
- 有机柔和曲线，拒绝生硬直角
- 多层错落堆叠的圆角面（卡片叠加），形成浅层次空间纵深感
- 前景卡片右下角可做**自然卷角**，还原实体便签/纸张质感（点缀，非必须）
- 右侧/角落散落细碎圆点（微尘粒子），呼应轻盈意境

### 3.3 间距与留白
- 充足留白，呼吸感
- 模块间距 24–32px，组内间距 12–16px

## 四、光影与质感（核心）

### 4.1 柔光弥散阴影
弱投影、边缘模糊虚化，整体悬浮轻盈，无厚重立体感。

```css
/* 卡片柔光阴影 */
box-shadow:
  0 4px 16px rgba(126, 200, 240, 0.12),
  0 1px 3px rgba(58, 74, 92, 0.04);

/* 悬浮态加强 */
box-shadow:
  0 8px 28px rgba(126, 200, 240, 0.20),
  0 2px 6px rgba(58, 74, 92, 0.06);
```

### 4.2 磨砂玻璃 / 通透薄纸质感
模拟亚克力磨砂通透感与轻薄纸张。

```css
/* 磨砂玻璃卡片 */
background: rgba(255, 255, 255, 0.65);
backdrop-filter: blur(16px) saturate(140%);
border: 1px solid rgba(255, 255, 255, 0.6);
```

### 4.3 渐变与高光
- 渐变平滑柔和，无强烈高光、无金属反光
- 顶部可加极淡高光（白色 8%–12% 透明），模拟光从上方洒落

### 4.4 线条表现
- 线条粗细均匀，柔边轮廓
- 装饰曲线采用同色系渐变描边，融入纸面，不割裂画面
- 分割线使用 `rgba(58, 74, 92, 0.06)`，极淡

## 五、组件规范（控制面板落地）

### 5.1 卡片 Card
- 圆角 16px + 磨砂玻璃背景 + 柔光弥散阴影
- 统计卡片：大数字（深岩蓝灰）+ 小标签（雾灰）+ 浅蓝渐变图标背景
- 可悬浮上浮 2px，阴影加深

### 5.2 按钮 Button
- 主按钮：浅蓝→淡紫渐变填充，白色文字，柔边，悬浮微上浮
- 次按钮：磨砂白底 + 浅蓝描边 + 浅蓝文字
- 危险按钮：蜜桃粉渐变（`#F5C6C6 → #F0A8A8`），深红文字
- 圆角 12px，内边距舒适

### 5.3 导航 / 侧边栏
- 通透半透明磨砂背景
- 活跃项：浅蓝渐变填充 + 柔光阴影 + 左侧 3px 圆角渐变指示条
- 非活跃项：透明，悬浮呈极浅蓝

### 5.4 表格 Table
- 行间距宽松，分割线极淡
- 表头：极浅蓝雾底，雾灰文字
- 行悬浮：极浅蓝高亮
- 操作列按钮使用次按钮样式

### 5.5 图表 Chart
- 折线/面积图：浅蓝→淡紫渐变填充，柔和曲线（smooth）
- 柱状图：同色系渐变柱，圆角顶部
- 饼图/环图：浅蓝、淡紫、蜜桃粉三色循环
- 无锐利网格线，坐标轴文字雾灰

### 5.6 弹窗 / 确认框
- 居中，磨砂玻璃面板，圆角 16px
- 背景遮罩：`rgba(58, 74, 92, 0.25)` + blur
- 危险操作确认：蜜桃粉强调，图标 + 明确文案

### 5.7 输入与表单
- 输入框：磨砂白底，浅蓝聚焦边框 + 柔光
- 表单标签雾灰，内容深岩蓝灰

### 5.8 状态标签 Tag
- 启用：浅蓝底 + 深蓝文字
- 禁用：雾灰底 + 灰文字
- 警告：蜜桃粉底 + 暖红文字
- 胶囊形圆角

## 六、应用图标规范

### 6.1 结构
- 多层错落堆叠圆角矩形便签纸，前后叠加形成浅层次空间纵深感
- 前景纸张右下角自然卷角，还原实体便签质感
- 外层统一大圆角方形外框（iOS/安卓裁切规范）
- 右侧搭配细碎圆点（微尘粒子）

### 6.2 配色
马卡龙通透渐变：浅天蓝 → 淡薰衣草紫 → 蜜桃粉暖渐变。
半透明叠透，图层相交自然混色。

### 6.3 质感
- 柔光弥散浅阴影，边缘模糊
- 磨砂玻璃 / 通透薄纸质感
- 渐变平滑柔和，无强高光金属反光
- 装饰曲线同色系渐变描边

### 6.4 适配 WinShare Panel
图标主体可融入"共享/连接"意象（如柔和的连接节点、叠层文件夹），但保持上述造型与色彩语言，不引入写实文件夹图标。

### 6.5 官方图标资源（已定稿）
项目已确定官方 logo，作为应用图标 / 标题栏图标 / 系统托盘图标 / 安装包图标的统一来源。

| 文件 | 路径 | 用途 |
|------|------|------|
| 源图 | `win-share-panel.png`（仓库根，1632×1504） | 唯一官方 logo 源，所有图标由此生成 |
| PNG | `resources/logo.png`（256×256） | 标题栏图标、系统托盘、favicon、UI 内引用 |
| ICO | `resources/icon.ico`（16/24/32/48/64/128/256 多尺寸） | Windows 应用图标、electron-builder 打包图标、WPF 托盘图标 |
| JPG | `resources/logo.jpg`（250×250） | 由源图派生的兼容副本，非独立设计 |

- 标题栏图标：使用 `logo.png`，显示尺寸 16×16
- 系统托盘图标：Electron 侧使用 `logo.png`；WPF 侧使用 `icon.ico`
  （`System.Drawing.Icon` 不接受 PNG，且 ICO 自带 16×16 帧更适合托盘）
- favicon：`src/index.html` 指向 `./logo.png`
- 应用窗口图标：`BrowserWindow({ icon: 'resources/icon.ico' })`
- 打包图标：`electron-builder` `win.icon` 指向 `resources/icon.ico`
- 如需更高清或多尺寸，从 `win-share-panel.png` 重新生成（居中裁切为正方形后缩放）

```css

  --color-accent: #E85D75;

  --hue-orange: #F08C1A;

  /* 背景 */

  /* 文字 */
  --color-text: #2F4159;
  --color-text-muted: #5E7488;

  /* 渐变 */
  --gradient-brand: linear-gradient(135deg, #3584EC 0%, #2456D6 100%);
  --gradient-nav-active: linear-gradient(135deg, #306EE8 0%, #2350C8 100%);
  --gradient-soft: linear-gradient(135deg, #E3F0FD 0%, #EDEBFB 100%);
  --gradient-backdrop: linear-gradient(135deg, #E9F2FC 0%, #F3F8FE 45%, #EDEFFB 100%);

  --blur-glass: blur(16px) saturate(140%);
}
```

## 九、窗口风格化（Electron）

> 不止内部 UI，**应用窗口外壳本身**也要呈现浅蓝调磨砂玻璃质感，与整体风格统一。

### 9.1 窗口形态
- **无边框**：`frame: false`，移除系统默认标题栏与边框
- **自定义标题栏**：磨砂玻璃质感栏，左侧应用名 + 图标，右侧窗口控制按钮（最小化 / 最大化·还原 / 关闭）
- **可拖拽区域**：标题栏设置 `-webkit-app-region: drag`，按钮区域设 `no-drag`，避免误触
- **大圆角窗口**：Windows 11 原生自动圆角；Windows 10 通过 `transparent: true` + CSS 圆角 + 柔光阴影模拟
- **最大化去圆角**：最大化时贴合屏幕边缘，去除圆角与外阴影，避免拉伸瑕疵

### 9.2 系统材质（Windows）
| Windows 版本 | 方案 | 说明 |
|--------------|------|------|
| Windows 11 | `backgroundMaterial: 'acrylic'` | 原生亚克力磨砂，透出桌面壁纸柔光 |
| Windows 11（备选） | `backgroundMaterial: 'mica'` | 云母材质，更淡更通透，与系统主题联动 |
| Windows 10 | `transparent: true` + CSS `backdrop-filter` | 无原生亚克力，用 CSS 模拟磨砂 |

- **失焦回退色**：Acrylic 失焦时自动变为纯色，将 `backgroundColor` 设为极浅蓝雾 `#F4FAFD`，保持品牌一致
- **版本检测**：主进程启动时检测系统版本，自动选择材质策略

### 9.3 窗口控制按钮
- **最小化**：磨砂透明底，悬浮浅蓝高亮
- **最大化/还原**：磨砂透明底，悬浮浅蓝高亮，图标随状态切换
- **关闭**：磨砂透明底，悬浮**蜜桃粉**（`#F5C6C6 → #F0A8A8`）+ 深红文字，符合危险语义
- 按钮宽高 46×32px，圆角 6px，图标线性柔和
- 双击标题栏切换最大化

### 9.4 标题栏视觉
- 高度 40px，磨砂玻璃 `backdrop-filter: blur(20px)`
- 底部 1px 极淡分割线 `rgba(58, 74, 92, 0.06)`
- 应用名：深岩蓝灰，14px，字重 500
- 左侧应用图标：16×16，浅蓝紫粉渐变小图标

### 9.5 主进程配置示例

```js
const isWin11 = /Windows 11|10\.0\.2[2-9]/.test(os.release()) // 简化判断
const win = new BrowserWindow({
  frame: false,                          // 无系统边框
  width: 1200, height: 800,
  minWidth: 960, minHeight: 640,
  backgroundColor: '#F4FAFD',            // Acrylic 失焦回退色（极浅蓝雾）
  backgroundMaterial: isWin11 ? 'acrylic' : undefined,  // Win11 原生磨砂
  transparent: !isWin11,                 // Win10 用透明窗口 + CSS 模拟
  show: false,                           // 就绪后再显示，避免白屏闪烁
  webPreferences: {
    preload: path.join(__dirname, 'preload.js'),
    contextIsolation: true,
    nodeIntegration: false
  }
})
win.once('ready-to-show', () => win.show())
```

### 9.7 兼容与风险
- **Win10 透明窗口圆角锯齿**：用外层柔光阴影补偿，圆角控制在 8–12px
- **Acrylic 失焦色突兀**：失焦回退色与品牌极浅蓝雾一致
- **拖拽误触**：所有可点击控件必须标记 `no-drag`
- **白屏闪烁**：`show: false` + `ready-to-show` 后再显示
- **全屏/最大化**：监听 `maximize`/`unmaximize` 事件，动态切换圆角与阴影类名
