# WinShare Panel UI 设计规范

> 浅蓝调 · 轻渐变扁平化 · 新拟态柔光磨砂玻璃风
> 版本：v1.0  |  更新日期：2026-08-06
> 适用：WinShare Panel 控制面板全部界面与应用图标

---

## 一、设计理念

### 1.1 风格定位
**轻渐变扁平化 · 新拟态柔光磨砂玻璃风**

清新治愈、年轻化、轻量化。拒绝厚重写实、锐利硬边、暗深色系与写实厚涂。让一个原本偏"系统工具"的文件共享控制面板，呈现出现代 App 的柔和质感，降低使用者的心理负担。

### 1.2 情绪调性
- 安静、文艺、温柔、简约治愈
- 悬浮轻盈，不压迫
- 信息清晰但不冰冷

### 1.3 设计禁区
- 复古厚重质感
- 暗深色系为主调
- 尖锐棱角与硬直角
- 写实厚涂、金属反光、强高光
- 厚重硬阴影

## 二、色彩体系（浅蓝调）

### 2.1 主色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 浅天蓝 | `#7EC8F0` / `#A8DCF5` | 主操作、导航高亮、品牌色 |
| 辅色 · 淡薰衣草紫 | `#C8B6E2` / `#D9CCEC` | 次级强调、图表渐变 |
| 点缀 · 蜜桃粉 | `#F5C6C6` / `#FAD9D9` | 提示、徽标、暖色点缀 |
| 背景 · 纯净白 | `#FFFFFF` | 主背景 |
| 背景 · 极浅蓝雾 | `#F4FAFD` | 卡片底、分区底 |
| 文字 · 深岩蓝灰 | `#3A4A5C` | 主文字 |
| 文字 · 雾灰 | `#8AA0B0` | 次级文字 |

### 2.2 渐变方案（马卡龙通透渐变）

主渐变（按钮、品牌、活跃态）：
```
linear-gradient(135deg, #A8DCF5 0%, #C8B6E2 55%, #F5C6C6 100%)
```
浅天蓝 → 淡薰衣草紫 → 蜜桃粉，冷暖柔色过渡，低饱和度高明度。

辅助渐变（卡片光晕、背景氛围）：
```
linear-gradient(135deg, #E8F4FB 0%, #F0EAF8 100%)
```

### 2.3 色彩质感
- 半透明叠透：图层相交处自然混色
- 无强烈明暗阴影，色调统一和谐
- 透明度建议：磨砂层 65%–80%，高光层 40%–55%

## 三、造型与圆角

### 3.1 圆角规范
| 元素 | 圆角 |
|------|------|
| 应用图标外框 | 大圆角方形（iOS/安卓裁切规范） |
| 卡片 | 16–20px |
| 按钮 | 10–14px |
| 输入框 | 10px |
| 标签/徽标 | 8px 或胶囊形 |
| 弹窗 | 16px |

### 3.2 造型语言
- 有机柔和曲线，拒绝生硬直角
- 多层错落堆叠的圆角面（卡片叠加），形成浅层次空间纵深感
- 前景卡片右下角可做**自然卷角**，还原实体便签/纸张质感（点缀，非必须）
- 右侧/角落散落细碎圆点（微尘粒子），呼应轻盈意境

### 3.3 间距与留白
- 充足留白，呼吸感
- 模块间距 24–32px，组内间距 12–16px

## 四、光影与质感（核心）

### 4.1 柔光弥散阴影
弱投影、边缘模糊虚化，整体悬浮轻盈，无厚重立体感。

```css
/* 卡片柔光阴影 */
box-shadow:
  0 4px 16px rgba(126, 200, 240, 0.12),
  0 1px 3px rgba(58, 74, 92, 0.04);

/* 悬浮态加强 */
box-shadow:
  0 8px 28px rgba(126, 200, 240, 0.20),
  0 2px 6px rgba(58, 74, 92, 0.06);
```

### 4.2 磨砂玻璃 / 通透薄纸质感
模拟亚克力磨砂通透感与轻薄纸张。

```css
/* 磨砂玻璃卡片 */
background: rgba(255, 255, 255, 0.65);
backdrop-filter: blur(16px) saturate(140%);
border: 1px solid rgba(255, 255, 255, 0.6);
```

### 4.3 渐变与高光
- 渐变平滑柔和，无强烈高光、无金属反光
- 顶部可加极淡高光（白色 8%–12% 透明），模拟光从上方洒落

### 4.4 线条表现
- 线条粗细均匀，柔边轮廓
- 装饰曲线采用同色系渐变描边，融入纸面，不割裂画面
- 分割线使用 `rgba(58, 74, 92, 0.06)`，极淡

## 五、组件规范（控制面板落地）

### 5.1 卡片 Card
- 圆角 16px + 磨砂玻璃背景 + 柔光弥散阴影
- 统计卡片：大数字（深岩蓝灰）+ 小标签（雾灰）+ 浅蓝渐变图标背景
- 可悬浮上浮 2px，阴影加深

### 5.2 按钮 Button
- 主按钮：浅蓝→淡紫渐变填充，白色文字，柔边，悬浮微上浮
- 次按钮：磨砂白底 + 浅蓝描边 + 浅蓝文字
- 危险按钮：蜜桃粉渐变（`#F5C6C6 → #F0A8A8`），深红文字
- 圆角 12px，内边距舒适

### 5.3 导航 / 侧边栏
- 通透半透明磨砂背景
- 活跃项：浅蓝渐变填充 + 柔光阴影 + 左侧 3px 圆角渐变指示条
- 非活跃项：透明，悬浮呈极浅蓝

### 5.4 表格 Table
- 行间距宽松，分割线极淡
- 表头：极浅蓝雾底，雾灰文字
- 行悬浮：极浅蓝高亮
- 操作列按钮使用次按钮样式

### 5.5 图表 Chart
- 折线/面积图：浅蓝→淡紫渐变填充，柔和曲线（smooth）
- 柱状图：同色系渐变柱，圆角顶部
- 饼图/环图：浅蓝、淡紫、蜜桃粉三色循环
- 无锐利网格线，坐标轴文字雾灰

### 5.6 弹窗 / 确认框
- 居中，磨砂玻璃面板，圆角 16px
- 背景遮罩：`rgba(58, 74, 92, 0.25)` + blur
- 危险操作确认：蜜桃粉强调，图标 + 明确文案

### 5.7 输入与表单
- 输入框：磨砂白底，浅蓝聚焦边框 + 柔光
- 表单标签雾灰，内容深岩蓝灰

### 5.8 状态标签 Tag
- 启用：浅蓝底 + 深蓝文字
- 禁用：雾灰底 + 灰文字
- 警告：蜜桃粉底 + 暖红文字
- 胶囊形圆角

## 六、应用图标规范

### 6.1 结构
- 多层错落堆叠圆角矩形便签纸，前后叠加形成浅层次空间纵深感
- 前景纸张右下角自然卷角，还原实体便签质感
- 外层统一大圆角方形外框（iOS/安卓裁切规范）
- 右侧搭配细碎圆点（微尘粒子）

### 6.2 配色
马卡龙通透渐变：浅天蓝 → 淡薰衣草紫 → 蜜桃粉暖渐变。
半透明叠透，图层相交自然混色。

### 6.3 质感
- 柔光弥散浅阴影，边缘模糊
- 磨砂玻璃 / 通透薄纸质感
- 渐变平滑柔和，无强高光金属反光
- 装饰曲线同色系渐变描边

### 6.4 适配 WinShare Panel
图标主体可融入"共享/连接"意象（如柔和的连接节点、叠层文件夹），但保持上述造型与色彩语言，不引入写实文件夹图标。

### 6.5 官方图标资源（已定稿）
项目已确定官方 logo，作为应用图标 / 标题栏图标 / 系统托盘图标 / 安装包图标的统一来源。

| 文件 | 路径 | 用途 |
|------|------|------|
| 源图 | `resources/logo.jpg` | 原始 logo，18KB |
| PNG | `resources/logo.png`（256×256） | 标题栏图标、系统托盘、关于页、UI 内引用 |
| ICO | `resources/icon.ico` | Windows 应用图标、electron-builder 打包图标 |

- 标题栏图标：使用 `logo.png`，显示尺寸 16×16
- 系统托盘图标：使用 `logo.png`，显示尺寸 16×16（建议额外准备 32×32 用于高 DPI）
- 应用窗口图标：`BrowserWindow({ icon: 'resources/icon.ico' })`
- 打包图标：`electron-builder` `win.icon` 指向 `resources/icon.ico`
- 如需更高清或多尺寸，从 `logo.jpg` 重新生成

## 九、窗口风格化（Electron）

> 不止内部 UI，**应用窗口外壳本身**也要呈现浅蓝调磨砂玻璃质感，与整体风格统一。

### 9.1 窗口形态
- **无边框**：`frame: false`，移除系统默认标题栏与边框
- **自定义标题栏**：磨砂玻璃质感栏，左侧应用名 + 图标，右侧窗口控制按钮（最小化 / 最大化·还原 / 关闭）
- **可拖拽区域**：标题栏设置 `-webkit-app-region: drag`，按钮区域设 `no-drag`，避免误触
- **大圆角窗口**：Windows 11 原生自动圆角；Windows 10 通过 `transparent: true` + CSS 圆角 + 柔光阴影模拟
- **最大化去圆角**：最大化时贴合屏幕边缘，去除圆角与外阴影，避免拉伸瑕疵

### 9.2 系统材质（Windows）
| Windows 版本 | 方案 | 说明 |
|--------------|------|------|
| Windows 11 | `backgroundMaterial: 'acrylic'` | 原生亚克力磨砂，透出桌面壁纸柔光 |
| Windows 11（备选） | `backgroundMaterial: 'mica'` | 云母材质，更淡更通透，与系统主题联动 |
| Windows 10 | `transparent: true` + CSS `backdrop-filter` | 无原生亚克力，用 CSS 模拟磨砂 |

- **失焦回退色**：Acrylic 失焦时自动变为纯色，将 `backgroundColor` 设为极浅蓝雾 `#F4FAFD`，保持品牌一致
- **版本检测**：主进程启动时检测系统版本，自动选择材质策略

### 9.3 窗口控制按钮
- **最小化**：磨砂透明底，悬浮浅蓝高亮
- **最大化/还原**：磨砂透明底，悬浮浅蓝高亮，图标随状态切换
- **关闭**：磨砂透明底，悬浮**蜜桃粉**（`#F5C6C6 → #F0A8A8`）+ 深红文字，符合危险语义
- 按钮宽高 46×32px，圆角 6px，图标线性柔和
- 双击标题栏切换最大化

### 9.4 标题栏视觉
- 高度 40px，磨砂玻璃 `backdrop-filter: blur(20px)`
- 底部 1px 极淡分割线 `rgba(58, 74, 92, 0.06)`
- 应用名：深岩蓝灰，14px，字重 500
- 左侧应用图标：16×16，浅蓝紫粉渐变小图标

### 9.5 主进程配置示例

```js
const isWin11 = /Windows 11|10\.0\.2[2-9]/.test(os.release()) // 简化判断
const win = new BrowserWindow({
  frame: false,                          // 无系统边框
  width: 1200, height: 800,
  minWidth: 960, minHeight: 640,
  backgroundColor: '#F4FAFD',            // Acrylic 失焦回退色（极浅蓝雾）
  backgroundMaterial: isWin11 ? 'acrylic' : undefined,  // Win11 原生磨砂
  transparent: !isWin11,                 // Win10 用透明窗口 + CSS 模拟
  show: false,                           // 就绪后再显示，避免白屏闪烁
  webPreferences: {
    preload: path.join(__dirname, 'preload.js'),
    contextIsolation: true,
    nodeIntegration: false
  }
})
win.once('ready-to-show', () => win.show())
```

### 9.6 自定义标题栏组件要点

```tsx
// 标题栏容器
<div className="titlebar" style={{ WebkitAppRegion: 'drag' }}>
  <div className="titlebar__title">WinShare Panel</div>
  <div className="titlebar__controls" style={{ WebkitAppRegion: 'no-drag' }}>
    <button onClick={minimize}>—</button>
    <button onClick={toggleMax}>{isMax ? '❐' : '□'}</button>
    <button className="close" onClick={close}>✕</button>
  </div>
</div>
```

### 9.7 兼容与风险
- **Win10 透明窗口圆角锯齿**：用外层柔光阴影补偿，圆角控制在 8–12px
- **Acrylic 失焦色突兀**：失焦回退色与品牌极浅蓝雾一致
- **拖拽误触**：所有可点击控件必须标记 `no-drag`
- **白屏闪烁**：`show: false` + `ready-to-show` 后再显示
- **全屏/最大化**：监听 `maximize`/`unmaximize` 事件，动态切换圆角与阴影类名
