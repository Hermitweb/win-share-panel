# WinShare Panel 重构：框架 / 性能 / UI 样式

## Context

工作区有一批未提交的 UI 统一改动（App.xaml 新样式、横向 Tab、设置页改造）。本次在此之上完成三件事：
1. **重构框架** — 消除重复代码、修复真 bug、清理死代码与临时插桩；
2. **优化性能** — 不动 PowerShell 生产通道（用户已确认保守路线，进程内池不启用），只优化调用频率与 UI 线程浪费；
3. **补齐 UI 样式** — 全量（含抽屉/向导/对话框），硬编码色全部替换为主题 token，让深色主题自洽。

硬约束（来自代码内既有结论，不重新挑战）：页面缓存三次回退已放弃（NavigationService.cs:50 注释），用节流缓解重建成本；静态槽位注入是用户确认的设计，不引入 DI 容器；只做最小 i18n（页头复用/补齐 Nav.* 键，其余文案维持硬编码中文）。

## 二、性能优化（保守路线）

**P1 用户页搜索去抖 + 去掉每键全量重查**：`Views/Users/UsersPageView.xaml.cs:166-172` `OnFilterChanged` 目前每敲一个字符 `await _vm.RefreshAsync()`（spawn powershell.exe）。改为：只设 `_vm.Keyword/_vm.OnlyEnabled`（VM setter 内部已本地重算行）+ `ApplyVm()`，不再调 RefreshAsync；外加 300ms DispatcherTimer 去抖。数据刷新仍由页面 Loaded、F5（RefreshRequested）、手动刷新按钮承担。

**P2 会话页停止每秒重绑表格**：`SessionsViewModel` 的 1 秒倒计时属性会触发视图全量 `ApplyVm()`（重建两个 DataGrid 的 ItemsSource，暂停时也在绑）。将 `Views/Sessions/SessionsPageView.xaml.cs:39-45` 的 PropertyChanged 处理器按 `e.PropertyName` 分流：`Countdown` → 只更新 `CountdownText`；数据类属性 → ApplyVm。

**P3 仪表盘刷新重入保护**：`DashboardViewModel.RefreshAsync` 加 `Interlocked` in-flight 标志，运行中直接跳过（skip 型，无排队无合并——区别于已回退的"并发合并"方案，语义简单）。跑全量 DashboardViewModelTests 验证。

**P4 告警气泡去重**：`DashboardViewModel.RefreshAsync` 中 AlertEvaluator 命中改为记录上轮签名集合，仅**新增**命中才 `Publish(AlertRaised)`（当前每轮对未恢复规则重复弹托盘气泡）。

**P5 ExportCsv 去 sync-over-async**：`DashboardViewModel.cs:287` `_fileSaver(...).GetAwaiter().GetResult()` → async 调用链。

**P6 节流铺开**：`Views/Settings/PageRefreshThrottle.cs` 目前只盖两个设置页。给 Shares/Users 页 Loaded 全量拉数加 `ShouldRefresh("shares"/"users", 10)`；总线 `RefreshRequested`（F5/托盘）绕过节流强制刷新——对齐设置页现有处理方式。

**P7 Logger 廉价路径**：`Core/Lib/Logger.cs` — 每行的 `Directory.CreateDirectory + File.Exists + FileInfo.Length` 改为缓存状态（目录创建一次、大小记忆轮转判断）；`ReadLogTail` 从全量 `File.ReadAllText`（最大 2MB）改为 FileStream 从尾部 seek 读取 ~1MB。文件自动禁写/测试钩子行为不变。

**P8 会话气泡跨线程修 marshal**：`BalloonRequested` 从轮询线程触发直连 `AppShell.ShowBalloon` → 经 Dispatcher marshal（VM 或视图侧均可，择一处）。

**P9 图表渲染缓存**：`Views/Charts/TrendChartControl.cs` OnRender 每次 `new Pen(new SolidColorBrush(...))` → 缓存 frozen 画刷；坐标轴/系列色改从主题 token 读取，订阅 ThemeChanged 后 `InvalidateVisual`（修深色下刺眼的浅色坐标轴）。

## 三、UI 样式全量补齐

**S1 主题 token 补齐**（`Theming/ThemeTokens.Light.xaml` + `ThemeTokens.Dark.xaml`，键名沿用现有 BrushXxx 惯例）：Info 标签底/字（替换 `#E6F4FF`/`#1677FF`）、Warn 底/字/点（替换 `#FFFBE6`/`#AD6800`/`#FAAD14`）、DangerDeep（替换 `#A8071A` 深红）、OverlayScrim（替换 `#40000000` 遮罩）等。浅/深两字典同键同构。

**S2 硬编码色清零**：4 个 XAML 页、`DashboardPageView.xaml.cs` 状态色兜底与协议分布行、`SharesPageView.xaml.cs` 协议横幅/水位、`SettingsUi.cs` 全部 fallback hex（改为按 token 取色）、各抽屉/对话框 → `DynamicResource` token。图表色板 `ProtocolPalette.cs` 保留（数据可视化色，主题无关）。

**S3 App.xaml 新增共享样式**：`RowActionButton`（行内/批量小按钮，DashButton 紧凑变体，含 Danger 前景变体）、`SegmentRadio`（胶囊分段单选——仪表盘趋势三态、抽屉区块选择）、`SoftDataGrid` 补 CellStyle（选中/悬停色走 token）、`ComboBoxItem` 样式、隐式 `ToolTip` 样式。

**S4 DataGrid 铺开**：`FileGrid`、`NfsSessionGrid`（Sessions）、`GroupsGrid`、`MatrixGrid`、`NtfsGrid`（Users）套 `SoftDataGrid`。

**S5 裸按钮套样式**：Shares 批量工具栏（批量启停=DashButton、清空/批量删除=DangerButton）、三页所有 DataGrid 行内操作按钮 → RowActionButton。

**S6 抽屉/向导/对话框全量**（全量补齐范围）：`ShareDetailDrawer`（TextBox→InputBoxSoft、ComboBox→ComboBoxSoft、CheckBox→CheckBoxSoft、按钮→DashButton/PrimaryButton、区块单选→SegmentRadio）、`ShareCreateWizardWindow`（27 处裸控件）、`ShareEditWindow`、`UsersDialogs.cs` 系列对话框、`FirstRunGuideWindow`、`CommandPaletteWindow`（圆角收敛 token）、`ProtocolTabViews.BuildPresets()` 的裸 ComboBox。

**S7 间距/圆角/字号归一**：页容器 margin 统一 20（Dashboard 的 24,22,24,28 一并归一）、卡片间距统一 16（SettingsUi.Card 的 14 对齐）、圆角收敛到 token 档位（3/4→8、6→10/12）、页头统一 PageTitle（22）+ 头下边距 16。

**S8 页头 i18n（最小）**：六页标题复用/补齐 Strings zh+en 键（Nav.Share/Users/Sessions、Dash.Title 已有；设置两页新增 2 个键），其余文案不动。

## 明确不做（本轮范围外）

- 页面缓存/路由保活重试（三次回退既有结论）；PS 通道切进程内池（用户已选保守）；DI 容器化；Core 命名空间与目录对齐（纯 churn）；ApplyVm→XAML 绑定的 MVVM 重写；协议分布网格重建与 RaiseAll/RaiseRowProps 全量通知优化（视图已合并调度，收益小）；全量 i18n。
